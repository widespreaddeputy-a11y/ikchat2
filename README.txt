ДЛЯ ПУБЛИЧНОГО ИСПОЛЬЗОВАНИЯ (чтобы все пользовались):

ВАРИАНТ 1 — БЫСТРО (1 минута, бесплатно, для РФ):
1. Зайди на https://tiiny.host
2. Нажми Upload → перетащи ВСЮ папку IKChat-PUBLIC-DEMO
3. Получишь ссылку вида https://t12345.tiiny.site
4. Скинь эту ссылку всем — кто откроет, тот в одном IKChat
   (пока чаты у каждого свои, но все на одном сайте)

ВАРИАНТ 2 — С ОБЩИМ СЕРВЕРОМ (чтобы сообщения были у всех):
Читай FREE_DEPLOY.md — нужно запустить FREE_SYNC_SERVER.js на Render.com (бесплатно)
Тогда все кто откроет ссылку будут в одном чате.

EXE (IKChat-FIXED.exe) — это ЛОКАЛЬНАЯ версия только для тебя.
Публичная — это ссылка выше.
